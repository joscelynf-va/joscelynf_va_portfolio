How to Host This Website for Free

Netlify (Easiest) Drag & Drop
  1. Save this code as index.html on your computer.
  2. Sign up for a free account at Netlify.com.
  3. Go to "Sites" and drag your file into the upload dropzone.
  4. Your website goes live immediately with SSL HTTPS!
GitHub Pages Custom Domain
  1. Create a free account at GitHub.com.
  2. Create a public repository named joscelyn-va.
  3. Upload index.html to the root folder.
  4. In Settings → Pages, select main branch and click Save.
Vercel Fast CDN
  1. Sign up at Vercel.com.
  2. Import your GitHub repository or use Vercel CLI.
  3. Click "Deploy" to publish your portfolio.
  4. Add your custom domain in settings for free.
